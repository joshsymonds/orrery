Research what the space looks like in November 2026

Nearly every tool has converged on a sidebar of sessions beside one conversation. Few of them answer the question you asked for: what is new since I last looked, on any device. That is where orrery's shared seen time is ahead.

Claude Code desktop

Every session in one sidebar, grouped by folder and filterable by status; split view; a context percentage per session; messages sent mid-turn queue above the composer. Attention is signalled by OS and phone notifications, and the docs describe no per-session unread mark.

Take the folder grouping and the queue above the composer. Add what it lacks: a seen time that the desk and the phone share.

Claude Code CLI queue

A message sent while Claude works shows greyed above the input, and Up pulls the queue back into the box to edit.

The queue docks above the send box, dim, with ↑ to edit. It never floats in the transcript.

cmux

A Ghostty-based terminal built because the stock notification is always “Claude is waiting for your input” with no context. Tabs show the latest notification text, panes get a ring, and ⌘⇧U jumps to the newest unread.

Show the question itself in the list, and keep one key that walks unread. orrery already has it: n.

cmux README

Warp and herdr

Both keep agents inside a terminal and add a status per pane: working, blocked or waiting, idle. Warp's orchestration view draws the parent with one pill per child agent.

Three states is the right amount, and orrery has them. A parent with children is the epic view; rings carry more than pills.

Cursor 3, Zed, Codex app

Each moved to one sidebar of agent threads grouped by project, whatever they run on: local, worktree, cloud, SSH, or started from a phone. Zed lists terminal threads in the same sidebar. Codex adds a review queue for finished runs.

One list for panes and headless sessions with no substrate marker. A queue of finished work is “New since you looked”.

Linear: the palette is the main way to act, single keys and G-then-key sequences, and every menu shows its key. Superhuman: j, k and e clear a queue, under a 100 ms rule. Raycast: Enter is the primary action, ⌘K lists the rest, and keycaps are drawn everywhere.
